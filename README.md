# Aquivora — Stage 1

Aquivora is a responsive study website built with plain HTML, CSS and JavaScript.

## Files
- index.html
- style.css
- script.js
- README.md

## Features
Dashboard, subjects, notes, MCQ quiz, flashcards, study timer, progress tracking, streaks, search, dark mode, local storage and mobile responsive design.

## Free publishing
GitHub Pages can host a static site from a public GitHub repository on GitHub Free.
For a user site, use the repository name `<your-github-username>.github.io`.

The exact `aquivora.study` domain is separate and requires owning that domain. You can first use the free GitHub Pages address.
